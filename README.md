# Prodestetic - Sitio Web

Sitio web estático de Prodestetic, publicado vía Cloudflare Pages.

## Estructura de carpetas

```
index.html              → página principal
css/styles.css          → estilos
js/main.js              → scripts
assets/img/logos/       → logotipos (PNG/SVG)
assets/img/fotos/       → fotografías del sitio
assets/iconos/          → iconos sueltos (SVG/PNG)
assets/video/           → videos
```

Para usar un archivo en el HTML, referencia la ruta relativa, ej:
`<img src="assets/img/logos/logo.png" alt="Prodestetic">`
